# 🚀 JM SAFARI TECH - Site Officiel

Bienvenue sur le dépôt du site web officiel de **JM SAFARI TECH**. 
Ce site a été conçu pour présenter nos services et partager notre expertise dans le domaine du numérique.

> **Slogan :** Rendre la technologie accessible à tous.

## 📋 À propos du projet

Ce site est une vitrine technologique mettant en avant nos quatre domaines d'expertise principaux :
*   💻 **Développement Web** : Création de sites internet modernes et sur mesure.
*   🧠 **Intelligence Artificielle** : Découverte et maîtrise des outils IA.
*   ⚙️ **Informatique** : Tutoriels, maintenance et conseils.
*   💡 **Innovation** : Idées et projets numériques pour l'avenir.

## 🛠️ Technologies utilisées

Ce site est généré de manière statique pour garantir une rapidité et une sécurité maximales.
*   **[Cecil](https://cecil.app/)** : Générateur de site statique (PHP).
*   **Markdown** : Pour la rédaction du contenu.
*   **HTML5 / CSS3** : Pour le design (Dark Mode, Responsive).
*   **PHP 8.4+** : Environnement d'exécution.
